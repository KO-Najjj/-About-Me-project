My Work

Project 1

SWN Skin is a skincare recommendation website that uses a questionnaire to suggest skincare ingredients based on a user's skin type, concerns, and acne type. Users complete a short skincare questionnaire by selecting their skin type, concerns, and acne type. After submitting their responses, the website generates personalized skincare ingredient recommendations and displays the results.

Project 2

City Courier is a 2D arcade game where players ride a bike through the city, collect packages while avoiding moving drones, and deliver them to the exit to complete each level. As players progress, the game becomes more challenging with additional packages to collect and more enemies to dodge.

Project 3

This project is a simple HTML webpage that displays the lyrics to Noah Kahan's song "Orbiter." The page includes the song title, artist name, album artwork, formatted lyrics using basic HTML elements, and a link to the official music video. It demonstrates the use of headings, images, text formatting, hyperlinks, and basic webpage structure.
